# E4 — Panel del médico

**Objetivo:** que el médico maneje desde una sola pantalla su agenda, sus pacientes y la información de cada uno.

| Dato | Valor |
|---|---|
| Historias | 6 |
| Puntos | 22 |
| Requisitos | RF-20 a RF-25 |
