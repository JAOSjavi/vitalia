## Historia

> Como clínica, quiero saber cómo se sintió el paciente con la atención, para detectar problemas antes de que se vayan.

## Criterios de aceptación

- **CA-1** · Dado que una cita se marcó como atendida, cuando pasa el plazo configurado, entonces el paciente recibe una encuesta breve por su canal preferido.
- **CA-2** · Dado que respondo la encuesta, cuando se registra, entonces la calificación queda asociada a la cita y al profesional.
- **CA-3** · Dado que la calificación es baja, cuando se registra, entonces el administrador recibe un aviso para revisar el caso.
- **CA-4** · Dado que no respondo, cuando pasa el plazo, entonces el sistema no insiste más de una vez.
