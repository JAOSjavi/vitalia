## Historia

> Como paciente, quiero decidir si mi resumen de atención se comparte con otras instituciones, para controlar hasta dónde viaja mi información de salud.

## Criterios de aceptación

- **CA-1** · Dado que se habilita la interoperabilidad, cuando se me solicita el consentimiento, entonces el texto explica qué se comparte, con quién y para qué.
- **CA-2** · Dado que no autorizo, cuando se genera un RDA, entonces no se envía a la plataforma y el sistema deja constancia del motivo.
- **CA-3** · Dado que autoricé, cuando revoco la autorización, entonces deja de enviarse desde ese momento, sin afectar los envíos ya realizados.
